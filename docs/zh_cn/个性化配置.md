# 个性化配置

本文介绍可选的编辑器辅助和项目已有的格式化工具。

## 编辑器辅助

- [Maa Pipeline Support](https://marketplace.visualstudio.com/items?itemName=nekosu.maa-support) 提供节点跳转、引用查找、截图、裁剪和任务调试，以 `assets/interface.json` 为项目入口。
- [markdownlint](https://marketplace.visualstudio.com/items?itemName=DavidAnson.vscode-markdownlint) 提供 Markdown 诊断，使用仓库的 `docs/.markdownlint.yaml`。
- Prettier 扩展可使用项目安装的版本，VSCode 工作区设置 `"prettier.configPath": "tools/format/.prettierrc"` 和 `"prettier.prettierPath": "tools/format/node_modules/prettier"`。

编辑器的 JSON Schema 关联采用下表。支持 MaaFramework 的插件可能已提供关联，可结合现有插件设置使用；局部覆盖结合基础节点核对。

| 编辑文件 | Schema |
| --- | --- |
| `assets/resource/*/pipeline/` 中的 JSON | `deps/tools/pipeline.schema.json` |
| `assets/interface.json` | `deps/tools/interface.schema.json` |
| `assets/interface/tasks/` 中的 JSON | `deps/tools/interface_import.schema.json` |

## 格式化与提交检查

在仓库根目录、已准备的 Python 虚拟环境中安装现有工具，并启用提交检查：

```sh
python -m pip install pre-commit
npm ci --prefix tools/format
python -m pre_commit install --config tools/checks/pre-commit-config.yaml
```

已安装的 hook 可通过同一安装命令更新配置路径。工具和配置分工如下：

| 对象 | 工具 | 配置来源 |
| --- | --- | --- |
| JSON / YAML | Prettier 与多行数组插件 | [Prettier 配置](../../tools/format/.prettierrc)、[npm 锁文件](../../tools/format/package-lock.json) |
| Markdown | markdownlint-cli2 | [Markdown 规则](../.markdownlint.yaml) |
| PNG | oxipng | [提交检查配置](../../tools/checks/pre-commit-config.yaml) |

版本、文件匹配范围及参数以提交检查配置为准。当前 Markdown hook 匹配 `docs/` 和 `README.md`；根目录 `AGENTS.md` 与 `.github/` 文档可使用编辑器的同一规则检查。

对本次修改的文件执行以下命令，将 `<文件>` 替换为实际路径；需要多个文件时依次列出路径：

```sh
node tools/format/node_modules/prettier/bin/prettier.cjs --config tools/format/.prettierrc --write <文件>
node tools/format/node_modules/prettier/bin/prettier.cjs --config tools/format/.prettierrc --check <文件>
python -m pre_commit run --config tools/checks/pre-commit-config.yaml --files <文件>
```

Prettier 命令用于 JSON / YAML 排版。JSON 使用 Tab 缩进，多行数组插件由配置所在目录解析；节点字段顺序与含义按 [Pipeline 编写规范](Pipeline编写规范.md)审查。pre-commit 中的部分检查会自动修正文件，完成后审阅 diff，并重新检查实际改动文件。

Markdown 中的文件名、节点名和命令使用行内代码或代码块，便于准确保留下划线、反斜杠等字符。文档检查同时核对链接、示例内容和渲染结果。
